# NUP Loader

A standalone loader for the Nintendo Switch 2 (kaiHEN), built with devkitPro.

## Build

Requires [devkitPro](https://devkitpro.org/) with the Switch 2 toolchain installed and `DEVKITPRO` set.

```sh
make
```

Output: `nup-loader.nro` (and `.elf`).
